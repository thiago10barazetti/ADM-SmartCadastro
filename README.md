# ADM SmartCadastro

## Sobre o projeto

O ADM SmartCadastro é um software desenvolvido para automatizar o cadastro de produtos no ERP ADM Sistemas a partir de arquivos XML de notas fiscais.

O objetivo é reduzir o tempo gasto com cadastros manuais, diminuir erros operacionais e padronizar as descrições dos produtos.

---

## Funcionalidades planejadas

- Leitura de XML
- Extração automática dos produtos
- Abreviação inteligente das descrições
- Geração automática do código de custo
- Cadastro automático no ADM Sistemas
- Aprendizado de descrições já cadastradas
- Banco de dados local
- Histórico de cadastros
- Interface moderna
